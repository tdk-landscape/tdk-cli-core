## Requirements
### Requirement: Stack terminology standardization
All references to logical grouping of resources SHALL use the term "stack" instead of "domain".

#### Scenario: Manifest field access uses stack
- **WHEN** code accesses the grouping field from a manifest
- **THEN** it SHALL use `manifest.get('stack')` and NOT `manifest.get('domain')`

#### Scenario: Cache keys use stack terminology
- **WHEN** the discovery cache stores configuration for logical groups
- **THEN** the cache key SHALL be named `stack_configs` and NOT `domain_configs`

#### Scenario: Autogenerated files use stack naming
- **WHEN** autogenerated index files are created for logical groups
- **THEN** the filenames SHALL contain `stacks` and NOT `domains`

#### Scenario: Function names use stack terminology
- **WHEN** a function generates an index of logical groups
- **THEN** the function name SHALL include `stacks` and NOT `domains`
