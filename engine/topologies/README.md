# Topologies (Incremental Migration)

This folder is the new destination for Tilt topology modules.

Current migrated modules (only currently needed runtime pieces):
- `platform/docker/*` (native compose/dockerfile/dockerignore/golden-layer generators + layers)
- `platform/net/proxy.star`
- `platform/state/relational.star`
- `platform/security/secrets.star`
- `platform/registries/local.star`
- `platform/observability/logging.star`
- `tilt/common/utils.star` (shared runtime utilities)
- `tilt/discovery/*` (native registry + native manifest scanner/grouping/dependency graph)
- `tilt/discovery/manifest/*` (native manifest constants/loading/normalize/validation)
- `tilt/config/{global,defaults,profiles,feature_flags}.star` (native config + native focus profile logic)
- `tilt/generators/*` (native vite/typescript/npmrc/nginx modules)
- `tilt/resources/*` (native libs/databases/infra-loader/watchers/orchestrator modules)
- `product_autogenerated_services_list/services.star`
- `product_autogenerated_resource_manifests/*`

Explicitly not created yet (not needed by current runtime):
- `platform/net/firewall.star`
- Most unreferenced files from the full target map.

Migration strategy:
- Keep behavior stable while moving runtime code out of `compat/`.
- Keep `compat/` as fallback shims during incremental cleanup.
